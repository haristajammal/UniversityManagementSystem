**University Management System**

A desktop-based University Management System developed using C# (WinForms/WPF) and MySQL. This project is designed to simplify and automate academic and administrative tasks such as student management, course handling, and fee records.

🚀 **Features**

Student, Faculty, and Admin management

Course and subject management

Fee and payment records

User-friendly desktop interface

🛠️ **Technologies Used**

Language: C#

Framework: WinForms / WPF

Database: MySQL

IDE: Visual Studio

Architecture: Desktop Application

🗄️ **Database**

MySQL database for storing user, academic, and administrative data

Supports CRUD operations

Structured relational schema

⚙️ **Installation & Setup**

Clone the repository:

git clone https://github.com/your-username/university-management-system.git


Open the project in Visual Studio

Import the MySQL database (.sql file) into your MySQL server

Update the database connection string in the project

Build and run the application


📌 **Use Case**

This project is suitable for:

Academic projects

Learning C# desktop application development

Understanding database-driven systems

Small to medium educational institutions
